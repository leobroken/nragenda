# ✂️ NRAgenda

Sistema SaaS completo de gestão, agendamento e controle financeiro para salões de beleza e barbearias. Desenvolvido com foco em alta performance, design moderno e experiência intuitiva.

## 🚀 Funcionalidades Principais

* **Agenda Inteligente:** Controle de horários por profissional e status de atendimento em tempo real.
* **Gestão de Clientes:** Cadastro completo e histórico de visitas.
* **Controle de Estoque:** Monitoramento de produtos para revenda e insumos internos com alertas de reposição.
* **Relatórios Mensais:** Acompanhamento de faturamento consolidado e serviços mais rentáveis.
* **Autenticação Segura:** Proteção de rotas e dados via Firebase Auth e Firestore.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, Tailwind CSS (via CDN) e JavaScript Moderno (ES6+).
* **Backend & Banco de Dados:** Firebase (Authentication & Cloud Firestore).
* **Hospedagem:** Compatível com GitHub Pages, Vercel ou Netlify.
